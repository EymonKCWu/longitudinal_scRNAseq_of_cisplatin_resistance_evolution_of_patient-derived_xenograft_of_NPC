# Longitudinal single-cell RNA sequencing study of evolution acquiring cisplatin resistance of patient-derived xenograft of nasopharyngeal carcinoma

Codes for single neoplastic cell analysis of Xeno76 with/without maximum tolerated dose (MTD) 5mg/kg cisplatin resistance from nude mice with/without cisplatin treatment.

Raw and processed data files, and metadata will be accessible from GEO later.
